Dataset changes and limits

364,000 hypothetical household/date scenarios. One complete rainfall date sampled uniformly per calendar quarter, not annual maxima. Age band selection is proportional to each synthetic household's member counts, then uniform within child/adult/elder bands. Original GIS values and synthetic composition/materials are preserved. These consistency changes do not establish demographic or physical realism.

The target simulator remains the illustrative v1 scoring rules; no labels were rewritten to make classification easier. Missing-source contributions remain hidden uniform integer draws per household/factor. The model cannot reliably infer independent latent contributions. Missing environment values remain missing; training-only medians handle them in the pipeline. Accuracy may therefore be limited even for this synthetic task.

Coverage is equal by barangay, not population weighted. Hypothetical locations are not verified residences. Historical rainfall is one shared NASA grid estimate; static land cover does not reconstruct earlier conditions. Household/date repetitions induce dependence, so no independent-row confidence intervals are claimed. Source manifests and quality_report.json are provided.

What is still needed for real validation

Observed household/event outcomes, consistent Low/Medium/High definitions, a representative sampling frame and independent external evaluation. A 98% synthetic score would not solve these requirements.
